🚀 How & Where to Host MultiSense Properly

⭐ BEST CHOICE (100% Free / Ready in 5 Mins) Render.com

Option 1: Deploy Full Stack to Render Web Service

Since this repository already has render.yaml and Dockerfile, Render will build Python 3.12, install OpenCV + PyTorch, and host both the Backend API and Frontend together on a single HTTPS URL with zero CORS issues!

  1. Push your code to GitHub: git push origin main
  2. Go to Render.com → Click New + → Web Service.
  3. Connect your GitHub repository.
  4. Configure:
    • Environment: Python 3 (or Docker)
    • Build Command: pip install -r requirements.txt
    • Start Command: uvicorn MultiSense.api.main:app --host 0.0.0.0 --port $PORT
  5. Under Environment Variables, add:
    • PYTHON_VERSION = 3.12.0
    • MONGODB_URI = (Your MongoDB Atlas connection string)
  6. Click Deploy Web Service. You will get a live URL: https://your-app.onrender.com!
Vercel + Render

Option 2: Decoupled Deployment

Host the static frontend on Vercel / Netlify / GitHub Pages and the FastAPI backend on Render / Railway:

  • Import repository into Vercel → Set Root Directory to MultiSense/frontend.
  • Deploy backend to Render as shown above.
  • In your Vercel frontend, click ⚙️ API Endpoint at the top and paste your Render URL!
Docker / VPS / Cloud Run

Option 3: DigitalOcean Droplet / AWS Lightsail / Google Cloud Run

docker build -t multisense-ai .
docker run -d -p 8000:8000 -e MONGODB_URI="your_uri" multisense-ai
Database

Setting up Free MongoDB Atlas Telemetry Storage

  1. Sign up at MongoDB Atlas and create a free M0 Shared Cluster.
  2. Under Network Access, add IP Address 0.0.0.0/0 (Allow Access from Anywhere).
  3. Under Database Access, create a database user (e.g. multisense_user).
  4. Click Connect → Drivers (Python) → Copy connection string.
  5. Paste it in ⚙️ Configure MongoDB URI on the dashboard or add to .env file.
